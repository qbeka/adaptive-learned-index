Adaptive learned index

An ordered index in C++20 that predicts where a key is, proves its correction is bounded, and measures when a rebuild pays for itself.

Watch the replay Results Read the report

The idea

A sorted array can answer any lookup, but it has to search for every key. A learned index fits a line to where keys sit, so one multiply lands close to the answer and a short search finishes the job.

Late inserts are the hard part. Buffering them is cheap until reads start paying for the buffer, and merging is expensive unless it is earned. This index measures both sides, leaf by leaf, and rebuilds only when the expected saving beats the measured cost.

  • Predictions use one integer multiply. No key ever becomes a float.
  • A bad model costs time and can never change an answer.
  • Reads of old data never pay for recent writes.
